# smallshop

Small Spring Boot CRUD demo for a tiny e-commerce schema: **Products**, **Customers**, **Orders** (with order items), and **Suppliers**. Each domain has a REST controller, a service, a JPA repository, and a ModelMapper-based DTO mapper. Originally generated by [Telosys Tools](https://www.telosys.org/) in 2018; modernized to current Spring Boot / Java.

## Stack

| Layer | Tech |
|---|---|
| Language | Java 25 |
| Framework | Spring Boot 4.0.6 |
| Persistence | Spring Data JPA + Hibernate |
| Database | Microsoft SQL Server (Hibernate `SQLServerDialect`) |
| Cache | Redis (via `spring-boot-starter-data-redis` + `spring-boot-starter-cache`) |
| DTO mapping | ModelMapper 3.2.x |
| Build | Maven (wrapper) |
| Containerization | Dockerfile based on `eclipse-temurin:25-jre` |

## Data model

```
Customer 1───* Order *───1 [Order]
                │
                └──* OrderItem *───1 Product *───1 Supplier
```

DDL and seed data live in `src/database/`:
- `sample-model.sql` — table definitions
- `sample-data.sql` — seed rows

The `Order` table is quoted as `` `Order` `` in JPA mappings because `ORDER` is a SQL reserved word.

## Run locally

You need a running SQL Server and Redis. Defaults expect them on `localhost` (1433 / 6379) with `sa` / `12345678x@X`. Adjust `src/main/resources/application.properties` if needed.

```bash
# Apply schema + seed
sqlcmd -S localhost -U sa -P '12345678x@X' -d smallshop -i src/database/sample-model.sql
sqlcmd -S localhost -U sa -P '12345678x@X' -d smallshop -i src/database/sample-data.sql

# Start the app
./mvnw spring-boot:run
```

App listens on `http://localhost:8080`.

## Build & containerize

```bash
./mvnw -DskipTests package
docker build --build-arg JAR_FILE=target/smallshop-0.0.1-SNAPSHOT.jar -t nttrungit90/smallshop .
docker run -p 8080:8080 nttrungit90/smallshop
```

## REST API

Each domain exposes a standard CRUD set under `/{resource}`:

| Method | Path | Description |
|---|---|---|
| GET | `/products` | List all |
| GET | `/products/{id}` | Fetch one |
| POST | `/products` | Create (JSON body) |
| PUT | `/products/{id}` | Update |
| DELETE | `/products/{id}` | Delete |

Same shape for `/customers`, `/orders`, `/suppliers`.

CORS is open via `rest/common/CORSFilter`. Validation errors are surfaced via `GlobalRestControllerExceptionHandler`.

## Observability

`management.endpoints.web.exposure.include=*` exposes all Actuator endpoints, e.g.:
- `GET /actuator/health`
- `GET /actuator/metrics`
- `GET /actuator/info`
- `POST /actuator/shutdown` (`management.endpoint.shutdown.enabled=true`)

## Layout

```
src/main/java/com/trung/smallshop/
  SmallShopApplication.java                 # Spring Boot entry (@EnableCaching)
  domain/
    entity/                                 # JPA entities: Product, Customer, Order, OrderItem, Supplier
    dto/                                    # ProductDto, CustomerDto, OrderDto, SupplierDto
  repository/jpa/                           # Spring Data JPA repos
  service/                                  # Service interfaces
    impl/                                   # Implementations
    mapping/                                # ModelMapper-based DTO mappers
  rest/
    controller/                             # CRUD REST controllers
    common/                                 # CORS filter + global exception handler
src/main/resources/
  application.properties
  ehcache3.xml                              # alternate JCache config (currently inactive — Redis is the active cache)
src/database/
  sample-model.sql
  sample-data.sql
Dockerfile
Jenkinsfile
```

## Modernization notes (May 2026)

This codebase was bumped from Spring Boot 2.0 / Java 8 (2018-era) to current versions:

- **Spring Boot:** 2.0.0.RELEASE → 4.0.6
- **Java:** 1.8 → 25
- **mssql-jdbc:** 6.4.0.jre8 → 13.4.0.jre11
- **ModelMapper:** 0.7.5 → 3.2.2
- **Validation:** added `spring-boot-starter-validation` (no longer transitive)
- **Imports:** `javax.persistence|annotation|validation|servlet.*` → `jakarta.*` (Jakarta EE 10)
- **Hibernate dialect:** `SQLServer2012Dialect` (removed) → `SQLServerDialect`
- **Naming strategies:** removed legacy `ImplicitNamingStrategyLegacyJpaImpl` / `PhysicalNamingStrategyStandardImpl` config (Hibernate's defaults are now sensible)
- **Redis properties:** `spring.redis.*` → `spring.data.redis.*`
- **Dockerfile base:** `openjdk:8-jdk-alpine` → `eclipse-temurin:25-jre`
- **Maven wrapper:** refreshed to 3.3.2 (was missing the wrapper jar)
